# Environmental Impacts of AI 🤖

This website explores the environmental impact of artificial intelligence, including its energy consumption, carbon footprint, and other websites for further research.
---


## Features  
* A dynamic carousel explaining AI’s environmental effects  
* Interactive graphs showing AI's energy consumption  
* A visually engaging layout with custom fonts and colors  

---

## Technologies Used  
- **HTML5**  
- **CSS3** (Flexbox & Grid)  
- **JavaScript** (for interactive elements)  
- **Google Fonts** (Anta & Ubuntu)  

---

## Installation  
To run this project locally, follow these steps:  

1. Clone the repository:  
   git clone [github.com/joellekai/AI-Environmental-Impact-Website](https://github.com/joellekai/AI-Environmental-Impact-Website)
2. Open index.html in a browser.

3. (Optional) Use a local server like Live Server for the best experience.

---

## Usage

* Scroll through different sections to learn about AI’s environmental impact.

* Click on different buttons to see the energy consumption of AI tasks.

* Explore the interactive carousel for more insights.
